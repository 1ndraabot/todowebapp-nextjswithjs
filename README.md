# Ruang Tugas

Starter project Next.js dengan tampilan front end berbahasa Indonesia. Daftar tugas di halaman utama dimulai kosong. Fungsi CRUD dan penyimpanan `localStorage` disediakan sebagai kerangka `TODO` untuk dikerjakan mahasiswa sesuai materi Markdown.

## Menjalankan secara lokal

Gunakan Node.js 20.9 atau lebih baru.

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000). Proyek ini sengaja belum memiliki logika pengelolaan dan penyimpanan tugas agar bisa dikembangkan sebagai latihan.
